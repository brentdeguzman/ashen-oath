ASHEN OATH v3.26.1 — COMPACT PACKAGE
===================================

This is a cleanup-only build of Ashen Oath v3.26. The actual game code,
combat mechanics, dungeon layouts, quests, shop selling, inventory dropping,
visual rendering, and saved-game format are unchanged.

Removed only files that are no longer used by the game:
- Old v3.23 treasure sprite variants (v3.24 chests remain)
- Unused generic dungeon and ruins floor atlases (all seven region atlases remain)
- Old large staircase props (new terrain-aligned staircase assets remain)
- Duplicate PNG hero portraits (WebP versions remain)
- Old promotional image and superseded update notes

No current game assets were intentionally removed. Existing saved games are
compatible with this build.
